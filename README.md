Investigación 

Clase: Es como una plantilla que establece las características y acciones que puede tener un objeto. En nuestro software, la clase Evento define la información y los comportamientos que tendrá cada evento registrado.

Objeto: Se crea a partir de una clase y contiene información específica. Por ejemplo, de la clase Evento podemos crear un objeto que represente un festival cultural con su propio nombre, fecha y lugar.

La diferencia entre una clase y un objeto es que la clase funciona como una plantilla que define las características y acciones que tendrá un objeto, mientras que el objeto es la representación de algo específico creado a partir de esa plantilla. Por ejemplo, la clase Evento define qué información debe tener un evento, mientras que un objeto sería un festival registrado con su propio nombre, fecha y lugar.

Atributos: Son las características que describen a un objeto, como el nombre, la categoría, la fecha, el lugar y la capacidad de un evento.

Métodos: Son funciones dentro de una clase que indican las acciones que puede realizar un objeto, como "mostrarInformacion()", que permite mostrar los datos de un evento.

Constructor: Es el método que se ejecuta al crear un objeto y permite inicializarlo con los datos necesarios. En nuestro software, el constructor de Evento recibe atributos como el nombre, la fecha y el lugar para crear cada evento con su información correspondiente.
